# 屏幕空间 AO V1（Cesium 1.143）

基于已有材质深度和Hi-Z的屏幕空间遮蔽估计，经过双边滤波后进入线性HDR。默认关闭；它与原生 `ambientOcclusion` 选项分开管理，避免叠加两个AO。

```js
pipeline.setScreenSpaceAO({ enabled: true })
pipeline.setScreenSpaceAO({ radius: 3, strength: 1, bias: 0.08 })
pipeline.getScreenSpaceAODiagnostics()
pipeline.setScreenSpaceAO({ enabled: false })
```

| 参数 | 默认 | 范围 |
| --- | ---: | --- |
| enabled | false | boolean |
| radius | 3米 | 0.1–20 |
| strength | 1 | 0–2 |
| bias | 0.08 | 0.02–0.5，方向夹角偏差 |

部分更新保留其他参数。参数变化不重写灯光、曝光、分辨率或外部原生AO状态。显式启用新AO时抑制原生AO；关闭时恢复仍由管线持有的原生AO请求。若外部控制器在新AO开启后打开原生AO，新AO旁路，不重复滤波。

## 数据和算法

AO自动请求材质通道与Hi-Z，保留调用者的显式开关。关闭AO时释放不再需要的依赖；仍被显式请求的材质/Hi-Z保留。消费者和计算都使用当帧数据，暂停/恢复/销毁与主管线联动。

半分辨率可见性阶段使用8个固定方向×4个径向采样，根据视空间位置差、几何法线、半径衰减与bias估计遮蔽。几何法线由相邻深度重建，避免法线贴图让平面产生自遮蔽。邻居距接收点超过半径时不参与法线重建，无法确定局部表面则保持中性。采样半径最多64个完整分辨率像素；近距离不保证遍历配置半径内全部区域。

复用Hi-Z第一层拒绝不相交的深度范围，并识别未知遮挡。负深度或未知标记会保守取消该估计，不能当作天空忽略。当前没有完整层级光线行进或GTAO积分，不用这些名称描述本实现。

随后使用横/纵各5 tap双边滤波：空间权重[1,4,6,4,1]，局部平面距离阈值max(0.02米,0.05×半径)，材质法线点积阈值0.85。完整分辨率合成使用四个半分辨率邻居并再次检查平面距离和法线；没有匹配样本的薄物体保持原色，不借用背景AO。

HDR合成为 `emission + (source - emission) * visibility`，其中emission限制在当前非负源颜色内。保留源alpha，不重复曝光/gamma。**当前调制的是非自发光场景辐射，包含直接光；尚未分离物理环境光/IBL贡献。**

## 顺序与范围

`HdrCoordinator143` 在单个原生执行集合上按优先级组织效果：AO(10) → 体积环境(20) → 原生后处理/ACES → 既有调色和SMAA。启停环境、重建质量档和更换AA不会颠倒这个顺序。协调器仅包装实例，解除最后一个效果时恢复自己仍持有的hook；不覆盖外部wrapper，退休hook不复活。

适用已验证的对称透视3D场景及受支持材质生产者。21个真实视锥的AO结果已验证；这不扩大环境模块原有的单视锥体积限制。

首版限制：

- 接收和遮挡估计跳过MASK、unlit、自定义材质、无有效法线和未知表面；这些像素保持中性。
- 受支持透明命令已使用 [逐像素覆盖遮罩](../channels/TRANSPARENCY.md)：透明像素保留原HDR，其他区域继续AO。含原生深度依赖、半透明轮廓等不可安全重放对象时，当前帧仍旁路；对象移除后自动恢复。
- 材质生产者的classification、复杂模板、WebVR等限制仍生效；非对称透视也旁路。
- 没有时域历史、运动矢量或TAA，不声称所有运动与轮廓都无闪烁。
- `valid`表示当帧有可用输出，不代表每个像素均有可靠AO估计。`getVisibilityTexture()` 的R为最终可见性，G为置信标记，不应读取raw阶段当作最终滤波结果。

## 资源和验证

三个半分辨率RGBA8目标加完整分辨率RGBA32F合成；当前1080p自有纹理去重合计39,398,400字节（37.57MiB）。材质与覆盖源41.53MiB、Hi-Z10.55MiB另计；尚未合并为统一纹理池。分配时检查实际framebuffer完整性，失败退回原HDR输入并释放资源；先关闭再开启才重试。resize重新检查新目标。

`node tests/rendering/run-ao.cjs` 使用既有Playwright和本地8766静态服务，输出独立 `plan/evidence/19-ao-*/` 目录。包含15项GPU数值检查、14项真实场景检查、校园默认参数前后截图、环境/AA排序、10轮暂停恢复、依赖保留及Viewer先销毁清理。Shader/管线/协调器/失败清理另有Node回归。

测试证明所覆盖配置，不能替代正式60秒前台整帧性能验收。AO短GPU查询不包含材质和Hi-Z依赖成本。默认仍关闭，可通过校园预览上的屏幕AO开关、半径/强度输入和状态按钮检查。

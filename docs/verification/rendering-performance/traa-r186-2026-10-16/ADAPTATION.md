## 实现与依据

- 保留 r186 的完整运动/历史深度、RGB moments/clipAABB、亚像素响应和 HDR 亮度加权；原始上游文件及 MIT 许可保持不变。
- 当前颜色和 3×3 统计重建到同一固定网格，历史使用同核，解决反复双线性重采样使移动细线变宽。重建核复用仓库批准基线，未引入其他引擎的裁剪/锐化规则。
- 低基础权重下实测半浮点历史有收敛误差，改为 RGBA32F。基础当前权重固定0.003，继续叠加 r186 的运动/亚像素项；初始化仅前32个样本做EMA校正，未恢复旧的静止高对比度分支。
- 局部有限表面显露/新出现时，历史 alpha 保存逐像素采样年龄，实机读回1/2/8/16/32。正常显示复用既有 RHI 拷贝恢复原始场景 alpha；GPU检查显示 alpha 始终1。无RHI的直接pass用一个自有display stage，已做实际源码路径检查。
- 当前及历史深度标签覆盖颜色真正使用的4×4范围，历史三次重建逐tap拒绝前景旧色，避免中心深度正确但邻居颜色跨遮挡泄漏。另补前帧眼空间米制拒绝，刚体Z运动使用motion.w，而非误用当前眼深。
- 修复 RHI 分配中途失败时未释放已分配资源，8个故障注入位置全部通过；修复默认相位回退仍写32的问题。默认8相位，4/16/32继续可选；32不保证比8稳定。最终UMD32相位实测窗格p95=0.7153、栏杆p95=3.8405，栏杆明显不及默认8相位的0.8780，因此不将32标为推荐画质档。

来源、坐标及每项偏离详见 [PORTING.md](../../../../src/antialiasing/reference/three-r186/PORTING.md)。

## 实景、输入与交互

实际校园加载70建筑GLB、60原生车辆，默认植被、水、云保持开启，分别检查traffic、traffic-close和building视角。建筑ROI p95从旧基线0.7041降至本轮约0.4985；车流和云不逐帧相同，该实景结果只作佐证，静止夹具才是受控对照。

平移、旋转、纯Z、相机+物体同时运动、启停、出现、遮挡、MASK及unsupported前景的GPU有效速度判定mismatch总计0。相机单独移动而模型静止时不增加motion draw。支持符合shader契约的独立opaque刚体GLTF；观察到的opaque不兼容项计入unsupported，透明pass在观察入口跳过，不应从unsupported=0推断透明已支持。蒙皮/morph/实例/自定义位移没有完整物体速度。

最终UMD的Label/Billboard在32相位下掩码逐像素稳定，拾取正确；原生selection边缘及最终青色轮廓在移动/重开后稳定。初版UI夹具在变化的HDR建筑背景上有1个字边像素跨过颜色阈值，不能据此判断glyph抖动；原失败数据保留，当前在固定天空背景隔离glyph覆盖，未放宽掩码门槛。

启停、暂停/恢复、704×462 resize、实际双视锥fallback/恢复通过；destroy后motion纹理释放，program/alias计数为0。实际history色/深度采样器为LINEAR/NEAREST。没有把普通刚体覆盖说成全场景零拖影。

## 性能与资源

同硬件、1920×1080、8相位、实际校园，300帧×3轮。frame/AA/motion轮换查询，AA和frame各300个有效GPU样本，CPU900帧；disjoint与unavailable均0。p50/p95取排序后floor(p*N)索引。

| 指标 | 基线 p50 / p95 | 最终适配 p50 / p95 |
| --- | ---: | ---: |
| GPU AA ms | 0.675 / 0.686 | 2.175 / 2.194 |
| GPU全帧 ms | 7.125 / 16.878 | 7.390 / 9.304 |
| CPU提交 ms | 9.80 / 16.20 | 10.50 / 17.50 |

AA本身增加约1.50ms，不能宣称性能优化成功。全帧负载有真实车流/云变化，不能将全帧p95下降归因AA。Motion采样300帧中123帧有辅助draw，活跃帧draw总和p50/p95为0.008192/0.114688ms；不包含begin/clear，未将无draw帧冒充有成本样本。

AA逻辑纹理分配：基线stage41,472,000+RHI49,766,400=91,238,400B（87.0MiB）；最终stage74,649,600+RHI82,944,000+motion33,177,600=190,771,200B（181.9MiB）。增加约94.9MiB。旧bytes遗漏RHI，不能直接用旧41.5MB减新190.8MB。这是AA相关已分配纹理字节，不是驱动/系统测得的整进程显存峰值；不含业务其他纹理、上游几何或驱动开销。本性能视角overlay.bytes=0；交互夹具640×420的UI overlay另分配4,300,800B，实际项目有Label/Billboard时需要另计。

未为降低已测2.2ms而再加缓存/重建框架。当前有效历史最多144个当前色读取、16个历史色及16个历史深度读取，另外current/pack各16个深度位置；仍有合并相邻重建足迹的成本空间。

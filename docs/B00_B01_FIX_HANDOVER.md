## 3. 未通过的场景验收与支持边界

**没有把这些项目写成“已通过”或放宽阈值：**

1. 校园campus-quality严格独立复比出现少量像素变化。额外逐像素诊断每镜头最多十余个变化像素，最大通道差21/255；1/255试验门槛拒绝。已撤下该组golden，保留原始差异；未扩大容差或用均值掩盖局部差异。它是既有效果组合的后续稳定性验收问题，本轮未修改其生产shader。
2. 真实影像长轨迹有provider失败，新门槛正确返回失败。单独近景可加载不等于整条轨迹通过；不把campus-geometry作为替代通过证据。
3. 排序透明完整接管仍无安全接点，本桥只观察并拒绝写入；B02/B03若需接管必须继续实现。
4. 本桥只证明OIT最终颜色接点；完整逐视锥light resolve、主绘制去重及透明独立照明尚属于B02/B03。
5. 上下文丢失后桥会安全退役；宿主整个Cesium场景自动恢复、全部硬件/材质/版本兼容不在本轮认证范围。
6. 多光源B13、植被仍暂缓，TAA生产代码未调整。旧宿主完整GPU夹具按后续消费者迁移，本轮不引用其测试数。

**复审结论：** 本轮修复范围内没有发现尚未处理的阻断性实现问题，可提交代码快照；这不等于所有场景验收通过或对未知硬件作零风险保证。阶段一总体仍处于开发中。

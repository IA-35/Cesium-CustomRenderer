# 动态天空系统

**这部分参考UE的超动态天空**

参考：[Ultra Dynamic Sky](https://www.ultradynamicsky.com/)

`G:\_UEProjectForWork\dongdaViewer5_5\Content\UltraDynamicSky`

---

**该模块在基础渲染能力之上，集成高质量的物理环境光照计算和GPU天气模拟，为数字孪生、城市灾害模拟、环境演练等场景提供逼真的动态自然现象。**



### ✅ 光照与天体模拟：

- **太阳与月亮天体计算（含月相变化）**：
  实时天体位置计算驱动光照方向和强度。
- **扩展大气散射模型**：
  综合考虑臭氧、大气密度、地球曲率、高度、湿度、气溶胶密度等，扩展Rayleigh/Mie模型。
- **空气透视渲染与远景蓝化**：
  支持地平线弯曲视差、湿润空气虚化等高级透视视觉模拟。



### ✅ 云层与天气动态：

- **多层体积云 GPU Raymarching 着色**：
  支持云形建模、局部扰动、光照漫反射、阴影叠加等细节表现。
- **GPGPU粒子天气系统**：
  - 🌧️ **雨天粒子**：落点溅射、表面反射、水面扰动。
  - 🌩️ **雷雨闪电**：云间电弧动画、雷光强度随云层密度变化。
  - ❄️ **雪天堆积模拟**：动态贴图模拟地表雪化、积雪厚度渐变。



### ✅ 多模态天气融合：

- **SkyBox/Sky Dome 实时颜色采样**：通过天空纹理动态反映天气色温变化。
- **GPU动态采样降噪（Temporal Sampling）**：增强体积云稳定性，提升连续帧一致性。
- **多种天气状态组合切换**：包括晴、阴、雷雨、夜雾、暴雪、云开日照等。
- **TAA混合降噪：**体积云支持基于taa抗锯齿的时间降噪算法

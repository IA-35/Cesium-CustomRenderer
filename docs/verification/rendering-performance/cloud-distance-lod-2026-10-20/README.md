# 体积云按距离降精度

2026-10-20。保留已有地平线范围扩展和高度保护，不新增距离截断或画质配置项。

## 实现

- 相机到采样点的距离 ≤8 km：保留原主采样密度和固定光照积分。
- 8–40 km：smoothstep 连续增加主步进跨度，同时减少次级光照采样。
- ≥40 km：主步长最多为原来的 4 倍；太阳、环境光上下半球、备用地面反弹和月光各使用 2 个光照样本。
- 主采样游标始终推进到路径末端，按实际米制步长积分，最后一个区段精确截断。颜色和加权云深度复用同一套调度；已有时间重建继续工作。
- 光照样本预算允许小数，最后一段按剩余长度积分；新增/消失的样本权重从零连续变化，避免简单取整导致的照明跳变。
- 近距离和接收面云影仍走原固定步长积分。密度场、噪声频率、细节侵蚀、云覆盖率、消光系数、球壳/地形遮挡以及远景覆盖范围均未调整。

修改集中在 `src/environment/cloudHorizon143.js` 与 `src/environment/volumetricClouds143.js`。没有加入全局动态分辨率、额外历史缓存、纹理或运行时质量开关。

## 验证方法和结果

业务页原始基线来自 `http://127.0.0.1:81/#/campus`。第一次刷新新版时调试连接跳转到登录页，业务页优化后的同场景测试未完成；用户反馈其浏览器没有看到登录页，两者的登录状态不能混用。没有读取凭据或绕过鉴权。

后续采用独立 Cesium 场景比较原构建、新构建、再回原构建。使用同一浏览器/GPU、1264×805 主画布、632×403 云缓冲、balanced 质量、覆盖率 0.38、云层 1600–2800 m、固定太阳时间和关闭云动画。独立场景没有校园模型/地形；仅用于云着色器和云通道性能验证，不能当作业务页 FPS 验收。

每个视角预热 90 帧、采集 120 个 GPU elapsed query。复用项目 GpuTimer，不同步等待 GPU。全部查询排空，pending=0、discarded=0，未丢失 WebGL context；各次页面错误列表为空。

| 相机高度／俯角 | 原构建 GPU P50 | 新构建 GPU P50 | 回原构建 GPU P50 | 相对首轮原构建 |
| --- | ---: | ---: | ---: | ---: |
| 3 km / −20° | 3.82 ms | 3.68 ms | 3.87 ms | 约降低 4% |
| 12 km / −30° | 4.76 ms | 2.18 ms | 4.81 ms | 约降低 54% |
| 25 km / −20° | 5.49 ms | 0.80 ms | 5.60 ms | 约降低 85% |

上述是 **cloud.march 颜色通道**的耗时，不是整帧或完整环境管线。25 km 相机的倾斜视线到云层通常已经超过 40 km，不能将表中的相机高度理解为 LOD 距离。

新版还实际运行了 performance 与 high 两档远景 shader：P50 约 0.32 / 1.01 ms，均为 120 个有效查询，无页面异常。静态截图检查未见新产生的距离截断或明显分界圈；远云光照细节允许比近景粗糙。没有完成所有连续飞行路径、昼夜变化和硬件的视觉验收。

数值与回归测试共 70 项通过，覆盖距离连续性、全路径消光积分、所有质量档预算、分数光照样本末段、球壳遮挡、云影和时间重建。构建通过，最终 CCR.min.js SHA-256：`75f118d305d4acd895ff8457f89ee35e157dccd98f663b60ba56f6dca0617234`；已同步业务项目 `public/js/CCR.min.js`，没有重打包业务 dist。

- `isolated.json`：最终 A/B/A GPU 数据和三档质量运行结果。
- `business-baseline.json`：业务页修改前数据，**无业务页优化后数据**。
- `tests.txt`：70 项定向测试结果。
- `isolated-before-*.png`、`isolated-after-*.png`：相同视角的静态画面对照。
- `benchmark.cjs`：本机独立场景脚本。原构建保留在系统临时目录 `ccr-cloud-distance-20261020/CCR.before.js`；脚本的浏览器调试端口和本机路径需要在复跑时核对。

限制：短时 GPU 通道基准不证明稳定 60 FPS，也不能抵消其他绘制、资源上传、垃圾回收或显存竞争造成的卡顿。原有高轨道高度范围保护依然保留，此次只调整采样精度。

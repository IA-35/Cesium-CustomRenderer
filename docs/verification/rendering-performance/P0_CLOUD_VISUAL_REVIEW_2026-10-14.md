# P0 云视觉修正记录

本轮以用户提供的平视、俯视截图为复现依据。性能测试暂停；以下均为正确性与画面检查，不表示 GPU 耗时或帧率达标。

## 根因与修改

1. 旧云形使用同一个随机标量场的插值与阈值，缺少独立形状和侵蚀。复用固定 three-geospatial `b012ad06d858fc035d88aacfd73f092f93c994e4` 的 Perlin-Worley、Worley、周期 Perlin 源码，离线准备 RGB 独立场。文件与许可保存在 `src/environment/reference/three-clouds/`，SDK 携带完整许可。
2. 旧太阳遮挡在另一噪声阈值上计数，与可见云体不一致。改为同一密度的连续消光、双 HG 相函数和多散射近似。
3. 高度包络在覆盖率阈值之后乘入，会产生铺满云层的低密度薄膜。先应用包络再阈值、侵蚀，并校正参考噪声偏高的数值范围。区分积云与层云形状。
4. 旧像素哈希与粗采样形成条纹，暂用确定性中点采样；真正的 STBN/云历史重建未实施。提高云视线预算以保留细节。
5. 云背景透射率、首次交点、WGS84 高度、天空/地面深度一并修正。源辐射与 RGB 透射率分别重建，再作用于全分辨率场景；先前的 HDR 差值方案已移除，避免低分辨率反照率污染云体。曾遗漏 `shellEmptyScene` 绑定导致环境 Pass 关闭，已补回并加入回归。
6. 原生地表大气在独立的 `showGroundAtmosphere` 路径中生效，不受 `fog.renderable` 单独控制。CCR 接管时同步退出原生天空/地表大气，停用或作用域不支持时恢复所有权。
7. 原消光系数 0.006 在新的形状阈值/侵蚀下会把云心渲染为薄雾。运行系数标定为 0.03；同一俯视取样中，有效云覆盖处透射率约从 0.1 降至 0.007–0.008，空隙仍保留原场景透射。该数值是当前形状场的标定，不直接等同于上游的 densityScale。

## 验证结果

- 全量测试：890 项，887 通过、3 跳过、0 失败。
- 嵌入语法检查：120 文件通过。
- Chrome WebGL2：三档 shader 编译/链接、零覆盖率、遮挡、透射恒等、太阳行星遮挡、云辐射能量上界通过。
- 实际 RGB 图集采样与 CPU 八角插值对照：最大误差约 `0.0001223`，包含负坐标及周期边界。
- 实际 resolve shader 的明暗反照率边界测试通过，RGB 源辐射不会被地表颜色混入或重复添加；RGBA32F 内部采用 RGB 光学深度编码，透射率相对量化误差上界约 3.2%，编码/解码先于过滤。
- 各视角：环境 HDR 有效、失败数 0；关闭所有介质时辐射为 0、RGB 透射率为 1；B08/B09 介质输出有效。分辨率在 0.5/1 间热切换及目标尺寸检查通过。
- SDK 已重建；未提交。新图集尺寸仍为 528×528 RGBA8，噪声字段数据随单文件 SDK 内嵌，包体相应增大。

## 验收边界

画面使用本地地形和周边白模。70 个校园 GLB 的完整验收未完成：当前本地目录缺少清单中的 `SM_NH_JZXG.glb`，加载在此中断，没有改动模型清单或伪造模型就绪。

原版数值对照、运行正确性与最终视觉质量是不同的验收项。本轮没有完成性能基准、LUT、云时域重建、完整太阳/天空照明标定，也不据此宣布整个 P0/渲染计划通过。

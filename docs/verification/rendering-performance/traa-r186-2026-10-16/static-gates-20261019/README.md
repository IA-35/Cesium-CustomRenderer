# 车辆播放触发静态地面闪烁：根因与修复

用户反馈：相机完全静止，地面斑马线等高对比细节仍闪烁；随后确认关闭车辆播放即可消失。

## 根因

上一轮 TaaPass 将 `motion.stationary` 用作全屏静态累积的前提。任意刚体矩阵变化都会让整屏退出保护，连远处不动的道路白线也恢复单帧方差裁剪；车辆更新间隔又使该条件反复切换。

前次“车辆关闭、固定时间”的验收没有覆盖此回归。重构前的静止判断主要依据相机和像素重投影，不会因为另一物体移动而对整屏切换同类分支；旧实现缺少真实物体速度，也正因此容易拖影。本次没有切回旧实现。

## 最终实现

- 当前运动/新表面继续使用真实运动向量；私有颜色历史 alpha 的绝对值保存采样年龄，负号标记运动表面。下一帧只在对应像素恢复严格历史拒绝和裁剪，静态背景保持累积。历史逐 tap 过滤同样识别负号。
- 物体从静止起步时，只看上一帧运动标记还不够，因为旧轮廓此前是静止的。复用 `projectOcclusionBounds`，在原 Motion 目标上用受 scissor 限制的四边形只写 alpha=-1，局部清除旧范围及重建边缘的颜色。没有添加新的历史纹理。
- 颜色几何提交结束后 `finish()` 为消失物体、以及不支持速度 shader 但具有包围范围的局部变化补遮罩。它们不再触发整屏降级。缺少包围范围等不可定位情况保留保守处理。
- 静止历史读取采用重构前已有的原则：相机静止且位移小于 0.001 像素时直接读取历史 texel，避免 ECEF 舍入误差导致反复三次插值。
- 显示 alpha 继续从场景输入恢复；负号元数据只存在于私有历史。拾取状态隔离保持生效。

地址：`http://127.0.0.1:5501/examples/campus.html`。70 个建筑、60 个车辆模型加载完成，车辆始终保持播放；相机和默认日照时间固定。画布 1280×720。

## 防止以拖影换稳定的检查

最终构建包运行 `scripts/performance/check-taa-regressions.cjs --bundle`：

- 远处刚体从静止起步并连续移动 16 帧，静态细点仍保持累积；最大 HDR 颜色变化约 0.00127。
- 从静止起步后，整个旧轮廓区域与当前重建颜色的最大误差为 **0**。仅加运动标记而没有旧范围遮罩时，该用例曾测得误差 **0.592**，所以没有交付那个不完整版本。
- 物体消失到实体背景和天空，下一帧旧颜色清理误差均为 **0**；不会为了保护远处白线而留下旧物体。
- pick 模型、pick 空白、pickPosition、drillPick 后历史连续，未误报整批新表面。
- 显示 alpha 正常；小点仍有持续辐射贡献，没有用擦除细节消除闪烁。
- RHI 以及直接 post-process stage 的无 RHI 路径均通过回归。

最终包结果保存在 regressions-final-bundle.json。代码测试：全量 1038 passed / 3 skipped / 0 failed；AA 专项 54 passed。构建及 diff 格式检查通过。

## 边界与代价

- 不新增历史纹理，复用 Motion RGBA32F 目标；需要局部拒绝时可能激活原先尚未分配的 Motion 目标。起步/出现/消失等帧会增加局部遮罩 draw 和读取，未重跑完整性能基准，不宣称 FPS 改善。
- 当前页面默认日照时间固定。本轮另一个隔离实验确认：仅推进场景时间也会使既有时间保护条件关闭静态累积。该条件未在本次车辆回归修复中移除，持续播放日照时间的稳定性不属于本次通过范围。gates-before.json/gates.json 保留这个结果。
- GPU 内部变形、材质内部变化仍没有完整的速度/变化语义；这里只验证受支持刚体运动、可定位的提交变化及静态背景。
- 未改车辆路线、播放和阴影业务逻辑，未回退整个 TAA。保留用户已有工作区修改；未提交或推送。

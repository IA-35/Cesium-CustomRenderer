# CCR 默认渲染与阴影区域整改

2026-09-15。按用户要求，默认天空/环境由CCR管理，默认云层改为shell，自定义方向光阴影不再固定校区；示例不再以native阴影作为正常运行路径。原生阴影仅保留显式对照选项。

## 实现

- CameraShadowCoverage每帧根据主相机视线选择地理中心，缩放时按视场扩展范围。贴图尺寸保持预算，覆盖尺寸用2次幂档位和滞回抑制频繁缩放，中心在光空间按局部像素网格稳定。跨区域自动重定位，无须业务调用setCampusOrigin。
- shadowDistance现在是最小关注范围的质量参数，不是固定校园边界。当前仍是一张自定义阴影图；高空扩大覆盖会降低每米精度，不等价于已经完成多级联近远景阴影。
- 默认shell环境首次启用可自行初始化坐标；近地跨80km后更新局部雾/光照参考，球壳云保持世界空间连续。setCampusOrigin兼容保留，但不控制阴影。
- 标准PBR接收端只改变直接光，保留原生IBL用于SSR差值替换；新增Globe接收端，在大气合成前调制影像表面光照，保留35%亮度下限。
- white-city与stage1可视示例使用CCR阴影。native ShadowMap禁用，避免两套阴影同时叠加。

## 实际验证

最终Node测试389/389通过，构建通过；阶段一源码/UMD联合回归通过，无页面错误。产物295,719字节，gzip101,150字节，SHA256 `032285465db22ee472824b61f0db8e14bbf788b7dfe49c0c069ecd198e7fe722`。当前为工作区修改，未提交或推送。

`scripts/check-camera-shadows.cjs` 在井冈山与北京之间往返，未重新调用setCampusOrigin，CCR阴影/环境均有效，原生阴影始终关闭；镜头从700m拉到10km时半覆盖范围从2048m扩大到8192m。显式给旧阴影setOrigin传北京坐标不会移动井冈山相机的阴影中心。

固定井冈山近景，分别检查阴影/SSR四种开关组合，截图RGB近黑像素数量均为0；SSR合成前非黑像素塌陷为黑的数值检查为0。此结果针对当前镜头，不能推断所有场景无伪影。最终截图 `docs/verification/camera-shadow-final.png`，报告 `camera-shadow-report.json`。

实际tiles材质/改色回退验证继续通过，SSR有2925个命中；CCR阴影25条投影命令，其中5条来自光源视角补选。此处命令/命中数只证明执行，画质还结合固定镜头截图检查。

## 边界

CCR默认管理和合成天空、云雾、照明参数、阴影、AA与后处理；Cesium仍提供场景管理、材质前向绘制和大气基础着色，不宣称已完成完整延迟PBR替换。天空多视锥、复杂透明分层、云投地阴影、CSM近远精度与地形高程精确拟合仍需后续推进。当前阴影定位使用椭球求交，山地地形与极端掠射角仍需专项验收。

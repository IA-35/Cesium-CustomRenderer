# 城市白模 HDR / Bloom / SSR

按用户指定 Tianjing scene2 的日间观感实施：使用完整城市几何和中性白色非金属 PBR，保留光照层次，克制 Bloom。夜间扫描条纹不属于本轮要求。

独立示例使用参考工程 city-set-draco.glb 的本地衍生副本，仅重设材质，不改原件。设置适当粗糙度及原生 IBL 环境回退；不对宿主或所有白模强制套材质。

SSR 优化屏幕边缘、擦边命中、短投影射线与步数预算临界的置信度渐隐。始终保留原生环境反射，不把无效命中补成错误倒影。保留未知遮挡/透明覆盖的拒绝规则；SSR 无法恢复镜头外真实建筑，环境回退是近似，不能承诺任意角度同一倒影。

验证：复用现有 SSR GPU 数值夹具；城市画面、反射输出、旋转镜头、多角度配置与运行错误检查；Node测试、源码/UMD构建。保留当前 HBAO/Bloom/球壳云等未提交修改。

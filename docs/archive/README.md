# 归档：架构调整前的文档

这里的 33 篇文档描述的是 **2026-10-13 架构调整之前**的 CCR，**不代表当前实现**。

## 为什么归档

2026-10-13 的 `cbab9e3` 完成了 Render Graph 与 WebGL RHI 迁移，其后又重写了环境（大气 / 体积云）
与提交路径。在那之前的一整套设计（阶段一 B00–B12）已被取代：

| 归档文档描述的做法 | 当前做法 |
|---|---|
| 通过 `context.draw` 多层 wrapper 拦截 | `ContextDrawDispatcher143` 单层统一 dispatcher |
| 资源由各模块自行创建 `C.Texture` / `C.Framebuffer` | `WebGLDevice143`（RHI）统一生命周期 + 资源池 |
| 手工管理 Pass 顺序 | `RenderGraph143` 声明/编译/别名/拓扑排序 |
| 噪声积分的体积雾与云求解 | 解析大气散射（Shadertoy 底本）+ 体积云 + Hillaire LUT |

因此这些文档对新读者是**误导源**，但作为**决策溯源**仍有价值（例如"为什么当初选了 A 而后来改成 B"）。

## 归档判定规则

同时满足两条才归档（见 `docs/README.md` 维护约定）：

1. 最后一次提交早于 2026-10-12；
2. 没有被 `src/ tests/ scripts/ examples/` 引用。

**只被根 README 历史提及不算活依赖** —— 那类链接已同步改写指向本目录。

## 使用建议

- **要了解当前实现**：回到 [docs/README.md](../README.md)，读 `01-`–`04-` 下的文档
- **要追溯设计演变**：在本目录里搜索关键词，注意核对日期与"已被取代"的判断
- **不要把这里的结论当作现状**：例如 `STAGE1_ACCEPTANCE.md` 的验收口径、`B0x_COMPLETION.md`
  的完成声明，都对应旧架构

## 注意

本目录内容**只读归档**，不随代码演进更新。若某篇文档里的信息重新变得有效，
应当**新写一份**放进 `01-`–`04-`，而不是在此修改。

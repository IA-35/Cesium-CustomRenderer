# 校园轻量植被

## 当前效果与入口

- `examples/campus.html` 默认使用官方 EZ-Tree 离线生成的三种针叶树原型和低面数草。
- `?vegetation=legacy` 对照原 GLB 树与两款草资产；`?treeSource=procedural` 保留原移植版生成器对照。
- 相机面板提供树木近景、松柏近景、草地近景。`?vegetationCheck=1` 才显示专项验收工具。
- 根据用户后续反馈，已移除本轮新增的草地绿色铺底面。保留原校园地形自身的材质。

## 树木

生成器使用 dgreenheck/ez-tree 官方源码固定提交 `dcf309bd86bd521083d9c70f01f2de45fdc7c457`。源码与许可证位于 `vendor/ez-tree-generator`。发布包 1.1.0 不含所需的同骨架多级几何接口，因此没有使用它代替当前官方源码。

使用官方 Pine Small / Medium / Large 完整树冠骨架，在生成网格时降低细分。松柏变体缩窄冠幅并降低起枝高度。三种目标高度分别是 9.5、10.5、8.5 米，取代原先 4.3 米的偏小原型。720 个点位与类型映射完整保留。近景保留更多针叶，取消中途试验版本对枝叶数量的过度削减。

| 原型 | LOD0 | LOD1 | LOD2 | LOD3 |
| --- | ---: | ---: | ---: | ---: |
| 松柏 | 10,422 | 4,128 | 1,586 | 744 |
| 松树 | 12,348 | 4,460 | 1,616 | 744 |
| 松树01 | 10,248 | 4,232 | 1,666 | 786 |

以点位 ID 生成稳定的随机旋转，散列增加 avalanche 混合，避免相邻编号朝向聚集。Three.js 纹理与 GLB 的垂直方向约定不同，导出时翻转 V 坐标，叶片根部与针叶尖端不会颠倒。

## 草地

- 使用现有上游 `grass.glb`，每簇 6 个三角形；原草为 796 / 1,358 个。
- 贴图为灰度草叶加透明通道，使用绿色线性着色与 alpha cutout；不会把透明背景按 RGB 亮度误判为草叶。
- 默认 4 簇/平方米；当前数据共 561,609 簇，每簇约 19–29 厘米高、约 30–37 厘米宽。
- 35 米内保留密度，至 220 米逐渐减量并停止绘制。不改变树木点位数量。
- 每个草地区块采样一个地面高度，排除建筑、周边白模和树；以该高度放置区块内草根，抬高 2 厘米。不是逐株贴地，也不是坡地逐点精确贴合。原固定高度低于部分地面约 30 厘米，缩小草后会被埋没，因此必须同时修正草根高度。

## 复现与验证

```powershell
npm run prepare:vegetation
npm run build
npm test
node scripts/dev-server.cjs --port 8878
```

生成的 GLB 和清单位于忽略目录 `assets/vegetation/ez-tree`；原树、原草和原清单没有覆盖。准备脚本依赖已有校园清单与点位数据。Three.js 仅为开发依赖，不进入浏览器包。

专项自动检查覆盖叶片 UV 方向、PNG 实体数据、目标高度、LOD 面数递减、随机朝向分布、草根高程、草贴图着色以及不新增地面几何。视觉与性能以当前浏览器复核记录为准，几何下降比例不能直接当作 FPS 提升比例。

本轮最终自动检查：699/699 通过，生产构建成功，差异空白检查通过。浏览器检查了松树近景、松柏近景、草坪近景，未记录到 console/page 错误；314 个草地区块均采样成功，0 个高度回退。

固定 1280×720、关闭周边白模、草地近景机位，预热 60 帧后每轮采样 180 帧，植被显示／隐藏／再显示：新方案整帧 GPU 中位数 7.040 / 5.927 / 7.231 ms，显示时主视图树木 329,968 三角形，草地 183,072 三角形（30,512 簇）。这些数据来自内置浏览器的单一固定机位，不是所有镜头的 FPS 保证。

# 2026-10-19 TAA 细像素闪烁定位

结论：当前 CCR TRAA 的单一最近深度标签不能区分亚像素覆盖变化与真正的遮挡显露。静态细结构随 Halton 相位被漏采时，米制历史拒绝会立即清除该像素历史 RGB；有限背景还把年龄重置为 1，导致周期性重新采样。实际校园屋顶像素已验证相同链路。天空背景另有历史 RGB 清除及方差盒收缩的叠加问题。

本次仅诊断；未修改 src、build 或正式配置。所有关闭分支的实验通过 Playwright 请求路由替换独立页面中的 shader，不构成候选交付版本。

## 3. 天空背景：保留年龄仍然清除了颜色

原有栏杆场景像素 (252,65)：最近眼深在 147 米与 0（天空）之间切换；局部年龄始终为 32，但漏采帧仍走直接输出当前 RGB 的分支。当前亮度标准差 4.74765，峰谷差 15.71520。

- 只跳过拒绝：标准差 4.19456。
- 只跳过裁剪：4.74765。
- 同时跳过拒绝与裁剪：0.23513，峰谷差 0.78740。

因此天空的年龄保留措施只解决了计数，未保护历史颜色；漏采导致 3×3 当前邻域收缩，也会经 clipAABB 丢掉历史细线贡献。不能只修有限背景的年龄或只改 gamma。

## 源码落点

- taaShaders143.js:28：taaDepthShader 将整个 4×4 重建足迹压成一个最近眼深。
- taaShaders143.js:207：resolve 对当前足迹同样取最近深度；不同相位可能选中不同表面。
- taaShaders143.js:258：relativeDisocclusion 用前后单值标签判断；此米制拒绝在 edge 例外之外始终生效。
- taaShaders143.js:261：无效历史直接输出 currentColor；有限背景年龄为 1，天空仅保留 alpha 年龄。
- taaShaders143.js:282：年龄重置后当前权重回到约 0.5/0.334，而非成熟历史的 0.003。
- taaShaders143.js:289：漏采邻域的方差盒还可能再次裁掉历史细节。

米制拒绝原本用于弥补 root-camera perspective depth 的远距离分辨率不足，该需求仍成立。问题是被比较的标签随采样覆盖变化，并不等同于真实表面变化。

## 修复方向与验收边界

1. 在历史接受处区分“采样覆盖改变”与“真实显露”，重新审视混合颜色对应的单一最近深度标签；保留真实显露、物体消失及局部新表面的拒绝。具体覆盖判据或深度表示需单独验证，不能仅凭相机静止接受所有历史。
2. 仅真实显露重启 acquisition；覆盖变化不能一遍遍清 RGB、重置年龄。深度 tap 过滤与中心接受应采用一致语义，避免中心放行后周围 tap 又把同一细节剔除。
3. 天空漏采帧须同步验证裁剪盒，不能只保留年龄或统一增大 gamma。禁止用停 jitter、全局关闭拒绝/裁剪或简单加大 2% 阈值当作修复。
4. 验收沿用当前 fixture，补足“亚像素小点 + 有限背景深度间距大于 2%”及“天空细线”用例；跟踪最坏像素/周期性波动、局部年龄和拒绝次数，同时检查细节平均覆盖、运动拖影和真实显露重置。
5. 现有窗格深度偏移仅 2/2.1 米、栏杆 3 米，相机眼深约 150 米，有限背景主要落在 2% 阈值以内或附近；未充分覆盖本次校园约 3.5%、小点 8% 的覆盖跳变。稀疏亮点仅占几个像素，整幅 p95/p99 与平均值可能几乎为零，不能替代最坏像素检查。

# P0 天空过曝与亮度验证

本轮处理视觉正确性，没有进行性能测试。

## 根因与最终改动

1. 仓库内 Shadertoy 源码将散射强度 40 与 `1-exp(-col)` 配对。将同一输出直接接到 Cesium 的 exposure=1.6、ACES、gamma，再施加原来的 clear 调色，出现大面积纯白。
2. 旧调色为 `(color-0.5)*1.1+0.5` 后乘 1.08 并 clamp。真实 GPU 灰阶读回显示 0.9 和 0.95 都变成 1；只关闭调色增强即可消除校准后云层的削顶。因此修正显示调色的高光处理，而不继续降低云照明或全局曝光。
3. 中间将大气换成云的太阳辐射 `[6.6,6.204,5.412]` 的试验不成立：两种模型的强度标尺不同，还重复施加暖色。虽然纯白比例下降，天空明显变暗。用户指出后撤销该方案。
4. 最终运行时大气使用独立白色 `atmosphereSunRadiance`，晴天默认为 `[20,20,20]`，沿用框架原生天空的强度；根据请求的太阳强度与天气缩放。大气自身负责太阳透射颜色与行星遮挡，不再受云的直射光淡出控制。原版 golden 函数依旧使用 40，常数和参考文件没有改动。
5. 调色使用保持 0/1 端点的对比度曲线和有界亮度增益。参数配置与曝光保持原值；非 neutral 调色的实际响应有变化，云、建筑等亮部都能保留更多层次。不是额外的 HDR tonemap。

## 实际页面与对比

实际加载 SDK 的 `/examples/campus.html`，使用本地地形、周边白模，关闭影像、交通、树、草和水；固定时间为校园示例默认白天，960×540，相机高程 300 m，单 frustum，环境半分辨率。分别以北向平视、沿太阳方位平视、朝太阳方向仰视，检查 clouds=true/false。

指标为画面上方 45% 区域，排除中心半径 5% 的太阳盘区域，统计 8-bit RGB 三通道均 ≥250 的近纯白像素比例。不是全图、GPU 时间或显存指标。

## GPU 回归检查

- 真实 WebGL2 编译并执行 performance/balanced/high 三档，保留与 vendored 参考积分的对照。
- 运行时大气辐射随独立太阳强度缩放；消光不变。太阳强度为零时，几何仍保持 `sceneColor * T`，天空不生成太阳散射。
- 实际显示调色 shader 的灰阶结果：0.9 → 0.92067，0.95 → 0.96312；修复前为 1 和 1。
- 调色 neutral/disabled 恒等、alpha=0.37 保持、亮度 0 为黑、对比度 0 为平灰；极小正亮度与最大亮度仍保留白端点且没有 NaN。
- 原有实际 resolve 反照率边界、RGB 透射编码和三维噪声插值检查仍通过。

全量检查：890 项，887 通过、3 跳过、0 失败；之后追加的天空强度回归，与该文件其余检查合计 7 项独立运行通过。嵌入语法检查 120 个文件通过。SDK 已重建，sha256 为 `74a1dceda09c3245089eedef7d93de042eb09b94c035e8bf2190abb5de921841`。

复现入口：`node scripts/performance/judge-atmosphere-exposure.cjs --label=after`（需设置 `CESIUM_PLAYWRIGHT`）。真实 shader 数值检查为 `node scripts/performance/check-shader-compile.cjs`。固定场景的天空亮度与纯白比例两项检查均通过。

## 验证边界

这是本地 Cesium 白模场景验证，未替代用户当前完整 GLB 场景验收，也未证明与截图中不同相机/太阳角度的 Shadertoy 画面逐像素一致。性能阶段继续暂停。

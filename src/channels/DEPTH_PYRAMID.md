# 共享深度金字塔（Hi-Z，Cesium 1.143）

Hi-Z是AO/SSR及保守遮挡判断的共享数据，本模块不执行视觉合成或DrawCommand剔除。后续新增的 [屏幕空间AO V1](../ao/README.md) 已使用第一层深度范围/未知标记。默认关闭；显式开启会自动请求材质通道作为深度来源，不修改调用者的显式材质开关。

```js
pipeline.setDepthPyramid({ enabled: true })
pipeline.getDepthPyramidDiagnostics()
const levels = pipeline.materialChannels.getDepthPyramidLevels()
// 每帧重新获取；null表示生产者/金字塔当前不可用。
pipeline.setDepthPyramid({ enabled: false })
// 若显式材质开关也为false，自动释放其依赖；否则保留材质通道。
```

## 深度契约 V2

材质通道的 `getDiagnostics().depthContractVersion` 为2，eyeDepth现在区分：

- 正数：已知、有限的米制视深度。
- 0：背景，没有已写入表面。
- -1：未知不透明遮挡物。其材质flags仍为0，不能把这个像素当作无遮挡背景。

这是相对V1“未知也写0”的语义变更。**不要把负值clamp成0后用于遮挡/追踪。** 目前没有为未知物体伪造或重建真实距离；源覆盖范围仍由材质通道的门禁决定。

## 层级契约

以源尺寸向上取整减半，从半分辨率开始直到1×1；源为1×1时仍生成一个1×1汇总。每个独立RGBA32F纹理保存：

| 分量 | 含义 |
| --- | --- |
| R | 区域内所有已知正深度的最小值；没有时为0 |
| G | 区域内所有已知正深度的最大值；没有时为0 |
| B | 区域内所有实际源像素都有已知正深度时为1，否则0 |
| A | 位掩码：1=未知不透明遮挡，2=透明覆盖，3=二者，0=均无 |

B只表示深度覆盖，不代表法线或其他材质字段有效。R/G存在值也不代表整个区域被覆盖。后续算法不得仅凭R/G宣称整块区域遮挡；遇到未知A=1应细分或保守拒绝，不能跳过该遮挡。背景-only区域为(0,0,0,0)，未知-only为(0,0,0,1)。

SSR启用时，生产者额外传入同帧R8透明覆盖：被覆盖的基础像素B=0，A按位加入2，父层按位OR聚合，R/G不透明深度保持不变。诊断`transparencyIncluded`标明此状态，`unknownMaskContractVersion=2`明确位定义。普通AO/显式Hi-Z不传覆盖时保持原0/1契约。透明SSR只消费不透明未知位，避免玻璃层显隐改变同一射线的遍历；不透明SSR/AO仍可将任何非零A视为保守遮挡。覆盖纹理只借用，不随金字塔销毁。

每一级使用整数texelFetch读取最多四个实际存在的子像素；奇数边缘不丢弃，不把越界位置作为背景或重复采样。归约层单独分配，输入输出从不使用同一纹理。它不是硬件自动生成的平均mipmap，也没有线性过滤。

Shader包含非有限值防护，将可观察到的NaN/Inf视为未知。当前驱动的NaN上传/readback会变为0，不能据此声称跨显卡非有限值传输已验证；生产者及消费者仍以有限正数、0、-1为正式契约。

## 所有权与有效性

归约紧随同帧材质重放执行，使用本帧eyeDepth。生产者每次update/render开始先使旧金字塔失效；不支持场景、旧帧、resize、源销毁、上下文丢失和错误不返回有效层。

消费者使用材质owner的 `getDepthPyramidLevels()`，同时检查生产者及归约有效性。不要直接绕过owner使用内部层数组，也不要跨帧、暂停或resize保存引用。独立导出的 `DepthPyramid143` 只检查其自身源/帧/尺寸，调用方需另行保证源的相机和场景范围。

resize会释放旧层，暂停/关闭释放所有归约纹理、framebuffer、Shader和Cesium RenderState引用；恢复后重建。分配/绘制失败后锁定，后续帧不反复分配；显式关闭/释放后才重试。默认关闭且从未请求时不创建材质或金字塔资源。

## 成本与验证

1080p共有11个归约层，纹理合计11,060,832字节（约10.55MiB），不含源材质通道39.55MiB和驱动开销。使用已有源，不再次绘制模型，但增加11个归约draw。

`node tests/rendering/run-hiz.cjs` 使用既有Playwright和本地8766静态服务，保存独立 `plan/evidence/18-hiz-*/` 证据。覆盖42组实际GPU有限数值输入，每一级全部texel与独立CPU原始区域参考比较；包含奇数尺寸、单行/单列、背景、未知、极大有限值及最后边缘。另将真实材质/校园整张源深度扫描与顶层结果比较，并运行材质GPU回归和10轮联合暂停/恢复、resize、依赖释放测试。

短时GPU查询仅用于诊断归约开销，不代表整体性能验收。[SSR](../reflections/README.md) 已使用多层深度区间和未知标记；实际遮挡反馈和时域历史仍未实现。

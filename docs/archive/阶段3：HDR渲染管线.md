# **HDR渲染管线**



**该模块为完全基于HDR渲染的物理渲染体系，技术核心源自一位海外Three.js开发者基于游戏引擎技术实现的****MIT协议项目，我们在此基础上完成了完整移植、适配并优化，拓展增强渲染，如TAA，SSS，SSR，游戏水面等。**



### ✅ Cesium底层优化：

- **延迟渲染管线（Deferred Rendering）**：
  替代原生前向渲染架构，实现 G-Buffer 结构，独立主渲染管线的一套单独gbuffer资源绘制管理机制。
- **UBO统一缓冲与动态FBO调度**：
  管理跨帧数据传输，提高多通道后处理效率。
- **SSR反射计算：**场景整体的一次屏幕空间反射，提升整体反射质感
- **SSS散射计算：**对水面、部分高光模型的全局次表面散射计算效果
- **TAA降噪+抗锯齿****：**高质量的时间抗锯齿，还支持体积云的时间混合降噪



### ✅ HDR大气与天空光预处理：

- **多级散射纹理生成**：包括Inscatter、Irradiance、Transmittance表，用于真实天空光模拟。
- **空气透视预计算贴图**：极大优化远景灰蓝效果与色温过渡。
- **天空预照明 LUT 加速渲染**：快速模拟全局大气照明与环境反射。



### ✅ HDR体积云预计算：

- 云层建模参数包括：
  - `Shape`**: 云层主体结构**
  - `Shape Detail`**: 局部细节纹理**
  - `Turbulence`**: 动态扰动**
  - `Volumetric Shape`**: 三维噪声体构型**
- **GPU Raymarch + 高质量体积光照**：支持层级阴影、云影、体积光、动态日照穿透等表现。



### ✅ HDR后处理渲染：

- **多通道曝光提取与Bloom泛光控制**
- **自适应Lens Flare（镜头眩光）**
- **多种Tonemapping曲线支持**：Filmic、ACES、Unreal等
- **自动曝光动态范围控制**：在不同照明强度下平滑调节亮暗对比
- **SSR反射计算：**场景整体的一次屏幕空间反射，提升整体反射质感
- **SSS散射计算：**对水面、部分高光模型的全局次表面散射计算效果



此外，整个HDR渲染模块在迁移Cesium渲染流程时做了较大优化和改动，在提升渲染性能的同时确保在高动态范围场景下也能保持稳定的帧率与光影一致性。
